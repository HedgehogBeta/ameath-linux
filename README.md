# Bue_Toolbox

自用工具合集。每个工具放在独立的编号目录中，保留各自的说明、依赖、测试和授权文件。

## 已有项目

| 编号 | 工具 | 简介 |
| --- | --- | --- |
| 01 | [Ameath Linux](01-ameath-linux/README.md) | Ameath 桌面宠物的非官方 Linux 移植版 |

运行或安装桌宠，请进入 `01-ameath-linux/`，按该项目的 README 操作。

## 目录约定

后续工具按 `02-工具名/`、`03-工具名/` 依次添加。每个目录都可以独立开发和打包；仓库根目录仅放工具索引与共用的 GitHub 工作流。

## 发布约定

Ameath Linux 的新版本使用 `ameath-linux-v版本号` 标签，例如 `ameath-linux-v1.1.9.4`。历史上的 `v1.1.9.2`、`v1.1.9.3` 标签和 Release 保留。
