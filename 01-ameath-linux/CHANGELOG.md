# Changelog

## 1.1.9.3

- 修复桌宠越过屏幕边缘时随机瞬移的闪现问题。
- 修复 GitHub 迁移后设置窗口因旧 Gitee 常量导入失败而无法打开的问题。
- 统一 Python 包、Debian 包和发行脚本的版本来源。
- Debian 包补充 `x11-utils` 依赖，确保 X11 全屏检测与窗口贴靠可用。
- 增加边缘移动随机回归测试、设置模块冒烟测试和发行包验证。

## 1.1.9.2

- 移植桌宠运行时到 Linux / Qt5。
- 支持 X11 活动窗口、全屏检测和窗口贴靠。
- 实现 XDG 开机自启、系统托盘、鼠标穿透和多实例。
- 保留上游 GIF、语音、音乐和字体素材。
- 添加内置音乐播放器与 GStreamer 音频后端。
- 修复托盘菜单回调对象被回收导致的操作失效。
- 添加单实例唤回和 `--quit` 退出通道。
